# Movie Memory

A small full-stack app where users sign in with Google, save their favorite movie, and get fun facts about it generated by OpenAI.

Built with Next.js (App Router), TypeScript, Tailwind, Postgres, Prisma, Auth.js and the OpenAI API.

> Work in progress. Full setup instructions, architecture overview and design notes will be added as the project is completed.

## Quick start

```bash
npm install
cp .env.example .env   # then fill in the values
npm run dev
```
